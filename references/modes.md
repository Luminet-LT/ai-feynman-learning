# 附加教学模式（来自学习提示词库）

Read this file when the user requests one of the non-curriculum modes below.

## 1. 考官模式（主动回忆测验）

Trigger: 用户想测试自己理解了多少。

Procedure:
1. 扮演严格但乐于助人的考官，从问 10 个问题开始，一次一个问题。
2. 难度递进：问题 1-3 初级；4-6 中级；7-8 高级；9-10 专家级。
3. 题型以客观题为主、选择题为主力：10 题中至少 7 道单选题（4 个选项 A~D），其余可为多选或判断题；把选项一并展示，让学习者作答后再判卷。此外再安排 1~2 道开放性思考题（无唯一标准答案），放在对应难度位置，学习者作答后按「参考思路 + 好答案要点」评判。
4. 一次只问一个问题并等待回答。
5. 每个答案后做四件事：打 0-10 分（对照掌握程度四档：0-3 未到「知道」/ 4-6 知道 / 7-8 会用 / 9 熟练 / 10 能教，见 references/levels.md「掌握程度档位」）/ 说对在哪 / 指出确切差距错误或薄弱点（选择题含干扰项为什么有迷惑性，思考题指出思路遗漏）/ 用简单语言重新解释遗漏部分。
6. 答案薄弱时，在进入下一个问题前问一个跟进问题；回答很好时略微增加难度。
7. 如用户提供了学习主题但没给考点，可先联网搜该主题的认证考试大纲或高频考点来定题。
8. 最后给出：最终得分 / 最强领域 / 最弱领域 / 简短复习计划 / 5 个最终挑战题（其中至少 3 道综合应用型单选题 + 至少 1 道综合思考题）。

Rule: 不要一次性给所有答案；让过程像真实的面试。

## 2. 速查表模式（一页速查）

Trigger: 用户想要一份可 5 分钟复习的一页速查表。

Include:
1. 用简单语言给出主题的简短定义。
2. 最重要的概念、规则、公式或步骤（清晰项目符号，不用长段落）。
3. 有助于解释的简单图表、流程图、表格或思维模型。
4. 3~5 个展示该主题在现实生活中如何运作的具体例子。
5. 应避免的常见错误或令人困惑的部分。
6. 一个快速的「使用前」检查清单。
7. 5 个快速测试记忆的问题：至少 3 道单选题（4 个选项）+ 至多 2 道判断题；另加 1 道开放性思考题检验能否举一反三。题目随速查表给出，但答案与解析不随附——学习者作答后由教练逐题揭晓（一句话解析 + 思考题参考思路）。
8. 制作前先联网核实主题中的关键事实与当前版本号（技术类主题尤其注意），并标注数据获取日期。

Rule: 实用、视觉化、初学者友好、易于扫描。

## 3. 资源规划模式（5 个最高价值资源）

Trigger: 用户想学习但不想浪费时间在低质量资源上。

Procedure:
1. 先用可用的联网工具（web 搜索 / 浏览器 / `curl`）搜索该主题的学习资源（这是本模式的核心：禁止只凭记忆列资源）；没有联网工具时如实说明并标注「未经联网核实」。
2. 为该主题找到 5 个最高价值资源（书籍 / 视频 / 课程 / 网站 / 社区 / 专家）。
3. 每个资源包括：名称 / 类型 / 值得花时间的原因 / 帮助学习的具体部分 / 最适合的学习者类型 / 难度级别（初级/中级/高级）/ 如何有效利用 / 一个警告（不要在什么上浪费时间）/ 来源链接（给搜索到的真实链接，不要编造）。
4. 按最佳使用顺序对资源排名。
5. 仅用这些资源给出一个 7 天学习路径。
6. 对时效敏感的信息（版本、价格、活动）标注数据获取日期。

Rule: 关注质量、清晰度和实际实用性；要信号，不要噪声；搜不到可靠来源时如实说明。

## 4. 费曼深入模式（解释-复述-补课循环）

Trigger: 用户想深入理解某个概念。

Procedure:
1. 扮演有耐心的老师，用简单语言向用户解释该主题，就当对方 12 岁：简单词汇 / 现实生活例子 / 类比 / 无多余术语 / 简短。讲解前先联网核实该概念的关键事实与最新说法。
2. 解释后，让用户用自己的话复述。
3. 审查复述：指出正确的部分；找到每个差距、错误、困惑或遗漏的想法。
4. 重新教授做错或遗漏的部分。
5. 让用户用更清晰的方式再次解释。
6. 重复循环，直到解释简单、准确且完整。
7. 最后给出该主题的最终清晰解释，供用户保存为笔记；再出 2~3 道单选题（4 个选项）和 1 道开放性思考题帮用户确认真的懂了——先让用户作答，作答后再逐题揭晓答案、一句话解析与思考题参考思路。

Rules: 解释清晰前不要继续；不增加额外理论负担；温和但清晰地纠正；困惑时使用例子；像互动对话而非讲座。
